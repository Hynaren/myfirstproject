# Daily Quest #2 — Claim Login Gift

## Goal

Complete the Daily Quest by claiming the currently available Login Gift.
The quest target is 1 claim.

## Confirmed high-level flow

The first implementation uses the game's Login Gifts entry point:

1. Tap the fixed Castle Events shortcut slot.
   - The slot is fixed, but the icon itself changes with the active event (e.g. Solo / Hell), so the icon is intentionally NOT used as a production template.
2. Wait for the Events screen.
3. Detect the Login Gifts entry/card.
5. Tap Login Gifts.
6. Wait for the Login Gifts screen.
7. Detect the currently claimable Claim button.
8. Tap Claim.
9. Verify the same claimable Claim visual state is no longer present.
10. Quest is complete after one verified claim.

The exact visual anchors must come from real LDPlayer screenshots.

## Vision strategy

Required templates:

- login_gifts.png
  - Stable visual anchor for the Login Gifts entry/card.
- claim_button.png
  - Active/claimable Login Gift button.
  - Do not use a disabled/already-claimed button as the primary target.

The routine must not depend on:

- hardcoded event-card coordinates;
- OCR of reward amounts;
- a fixed reward/day index;
- hardcoded event-card positions;
- assumptions about the current Login Gift reward;
- web screenshots as production templates.

All target coordinates come from Detector results.

## Verification

The routine verifies the claim action by rescanning the active Claim template.

Success:
- Fixed Events shortcut tapped and Events screen reached;
- Login Gifts entry detected and opened;
- active Claim button detected;
- Claim tap succeeds;
- active Claim visual state is no longer detected.

Failure:
- any required template is missing;
- the fixed Events shortcut tap fails;
- any required target is not detected;
- any tap fails;
- the active Claim state remains visible after the claim.

## Safety

Missing templates must fail before any game interaction.

Global popup safety remains owned by AutomationEngine / PopupManager.
This routine does not duplicate popup handling.

## Architecture

AutomationEngine
→ Global Popup Safety
→ QuestManager
→ ClaimLoginGiftRoutine
→ ActionEngine
→ Detector / Vision
→ ADB
